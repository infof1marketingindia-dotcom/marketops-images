# Case study inbox

Add one file here for each real case study. The case study agent checks this folder every day and publishes one file per day on marketops.in.

Copy `TEMPLATE.md`, rename it (for example `avyro-amazon.md`), fill it in and commit it. You can also add a PDF or PPTX with the same details.

Rules:
- Use only real results you can prove.
- Write "yes" for client_name_approved only if the client has agreed. If not, the agent will not name the brand.
- This repository is public, so do not add private client data you would not publish.
